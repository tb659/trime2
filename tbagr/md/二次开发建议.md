## 核心必改目录（按优先级排序）

### 1. 业务逻辑核心（最高优先级）
`app/src/main/java/com/osfans/trime/`
所有输入法业务代码都在此，子模块按需求选择：

| 子模块/文件 | 开发场景 |
|--------------|----------|
| `TrimeService.java` | 输入法服务入口，所有按键事件、文本输入、生命周期逻辑都在这，改核心输入行为必看 |
| `core/` | RIME 引擎集成层：<br>• `Rime.java`：和原生 RIME 库交互的核心桥接<br>• `RimeProto.java`/`RimeMessage.java`：输入输出数据结构<br>• 改输入法引擎交互、候选词逻辑、输入状态管理都在这 |
| `keyboard/` | 键盘相关：<br>• `KeyboardView.java`/`KeyView.java`：键盘绘制、按键交互<br>• 各类键盘适配器：改键盘布局、按键行为、手势操作 |
| `candidate/` | 候选词模块：<br>• `CandidatesManager.java`：候选词管理<br>• 各类候选词视图/适配器：改候选词显示、分页、交互 |
| `theme/` | 主题系统：<br>• `ThemeManager.java`：主题加载切换<br>• `Style.java`/`KeyStyle.java`：样式定义，改界面外观必看 |
| `InputView.java`/`RootInputView.java` | 输入法主UI容器，管理键盘、候选词、工具栏的显示逻辑 |

### 2. 功能扩展（高优先级）
| 目录/文件 | 开发场景 |
|------------|----------|
| `data/` | 数据管理：<br>• `opencc/`：繁简转换词典管理<br>• `userdict/`：用户词典管理，改词典、繁简功能在这 |
| `dialog/` | 各类设置对话框：改输入法设置页、方案切换弹窗、主题选择页等 |
| `speech/` | 语音输入模块：扩展语音识别能力 |
| `util/` | 公共工具类：加通用方法、扩展工具能力 |

### 3. 原生层（仅改核心引擎/JNI时碰）
`app/src/main/jni/`

| 子目录 | 开发场景 |
|----------|----------|
| `librime_jni/` | Java 和 RIME 原生库的 JNI 桥接，改 JNI 调用、加原生接口在这 |
| `librime/` | RIME 核心引擎（C++），一般不用改，除非要改输入法引擎底层逻辑 |
| `OpenCC/` | 繁简转换原生库，一般不用改 |

### 4. 资源/配置（必碰）
| 路径 | 开发场景 |
|------|----------|
| `app/src/main/res/` | Android 资源：布局、字符串、图片、样式、配置 |
| `app/src/main/assets/` | 资产文件：默认配置、字典、主题资源 |
| `app/src/main/java/com/osfans/trime/Config.java` | 配置文件解析，改配置加载逻辑在这 |
| `doc/` | 键盘/配置说明文档，改配置结构、加新配置参数参考 |

## 可选修改目录
| 路径 | 场景 |
|------|------|
| `codegen/` | KSP 代码生成模块，仅修改注解处理器相关逻辑时碰 |
| `app/src/test/` | 测试用例，改了核心逻辑建议补充对应测试 |
| `app/build.gradle.kts` | 模块构建配置，加依赖、改构建参数时修改 |
| `gradle/libs.versions.toml` | 依赖版本管理，统一修改依赖版本 |

## 完全不用碰的目录（第三方集成库）
这些是直接引入的第三方库，二次开发**不建议修改**，避免破坏原有功能：
- `com/android/cglib/`：Dex 工具库（集成第三方）
- `com/androlua/`：Lua 脚本支持库（集成第三方）
- `org/luaj/`：Lua 解释器（完整第三方库）
- `com/myopicmobile/textwarrior/`：文本编辑器组件（集成第三方）
- `com/nirenr/`：辅助工具类（基本无需修改）

## 按开发场景快速定位
| 开发需求 | 聚焦目录 |
|----------|----------|
| 改键盘布局/按键行为 | `keyboard/` + `res/` |
| 改界面主题/样式 | `theme/` + `res/` |
| 改输入逻辑/候选词 | `core/` + `TrimeService.java` + `candidate/` |
| 加新功能模块 | 在 `com/osfans/trime/` 下新建对应模块包 |
| 改设置页/对话框 | `dialog/` + `res/layout/` |
| 改用户词典/繁简转换 | `data/` |
| 改语音输入 | `speech/` |
