### 核心类职责

| 类名                    | 职责                         | 文件位置                       |
|-----------------------|----------------------------|----------------------------|
| `RootInputView`       | 根布局容器，管理左右侧边栏、中心区域、工具栏     | `RootInputView.java`       |
| `InputView`           | 键盘视图管理器，负责键盘切换、缓存、Lua 脚本加载 | `InputView.java`           |
| `KeyboardView`        | 键盘视图基类，管理所有按键集合和触摸事件       | `KeyboardView.java`        |
| `RowKeyboardView`     | 行布局键盘（按行排列按键）              | `RowKeyboardView.java`     |
| `AbsKeyboardView`     | 绝对定位键盘（自由定位按键）             | `AbsKeyboardView.java`     |
| `FlexboxKeyboardView` | Flexbox 弹性布局键盘             | `FlexboxKeyboardView.java` |
| `KeyView`             | 单个按键视图，包含文本、背景、滑动提示等       | `KeyView.java`             |
| `Key`                 | 按键数据模型，存储按键配置信息            | `Key.java`                 |
| `KeyStyle`            | 按键样式配置，定义外观和行为             | `KeyStyle.java`            |

### 2.2 setKeyboard 方法详解

**文件**：`InputView.java` 第 169-232 行

```java
public void setKeyboard(String id) {
    // 特殊处理：切换到上一个键盘
    if (".last".equals(id)) {
        if (oldView != null)
            setKeyboardView(oldView);
        return;
    }

    // 相同方案无需重复加载
    if (id == null || id.equals(mCurrentSchemaId)) return;
    mCurrentSchemaId = id;

    // 解析实际的键盘ID（多级回退逻辑）
    id = getKeyboardId(id);

    // 优先从缓存获取键盘视图
    KeyboardView targetView = mViewCache.get(id);

    if (targetView == null) {
        // === 缓存未命中，需要创建新键盘 ===

        // 步骤1: 初始化Lua运行环境
        Globals globals = JsePlatform.standardGlobals();
        globals.finder = this;  // 设置资源查找器

        // 步骤2: 加载对应方案的Lua脚本
        LuaValue func = globals.loadfilex(id + ".lua");

        try {
            if (func.isfunction()) {
                LuaValue ret = func.call();  // 执行Lua脚本

                // 如果Lua返回自定义View，直接设置
                if (ret.isuserdata(View.class)) {
                    setKeyboardView(ret.touserdata(View.class));
                    return;
                }
            }
        } catch (Exception e) {
            ThemeManager.sendMsg("setKeyboard " + e);
        }

        // 步骤3: 根据Lua配置创建对应的键盘视图类型
        if (globals.get("rows").istable()) {
            targetView = new RowKeyboardView(getContext(), globals);
        } else if (globals.get("flex_box").istable()) {
            targetView = new FlexboxKeyboardView(getContext(), globals);
        } else if (globals.get("keys").istable()) {
            targetView = new AbsKeyboardView(getContext(), globals);
        } else if (globals.get("key_maps").istable()) {
            // 符号键盘特殊处理
            SymbolsKeyboardView symbolsView = mSymbolsViewCache.get(id);
            if (symbolsView == null) {
                symbolsView = new SymbolsKeyboardView(getContext(), globals);
                mSymbolsViewCache.put(id, symbolsView);
            }
            TrimeService.getInstance().showCustomView(symbolsView);
            mCurrentSchemaId = null;
            return;
        } else {
            // 未知布局类型，回退到默认qwerty36键盘
            func = globals.loadfilex("themes/default/keyboards/qwerty36.lua");
            if (func.isfunction())
                func.call();
            targetView = new RowKeyboardView(getContext(), globals);
        }

        // 步骤4: 存入缓存
        mViewCache.put(id, targetView);
        if (targetView.isLock()) {
            mViewCache.put(".default", targetView);
        }
    }

    // 步骤5: 设置最终找到的键盘视图
    setKeyboardView(targetView);
}
```

### 2.3 键盘ID解析逻辑（getKeyboardId）

**文件**：`InputView.java` 第 240-280 行

回退优先级：

1. 缓存中已有 → 直接返回
2. 键盘文件存在 → 返回
3. 主题管理器映射 → 解析后返回
4. 当前Rime方案ID → 再次尝试
5. 固定默认键盘 → 最终回退

```java
private String getKeyboardId(String id) {
    // 1. ID为空时，尝试获取默认键盘配置
    if (id.isEmpty()) {
        String k = Config.getKeyboard(".default");
        if (!TextUtils.isEmpty(k)) {
            if (mViewCache.containsKey(id))
                return id;
            if (new File(findFile(id + ".lua")).exists())
                return id;
        }
        // 回退到当前Rime方案ID
        id = Rime.getRimeStatus().getSchemaId();
    }

    // 2. 检查缓存
    if (mViewCache.containsKey(id))
        return id;

    // 3. 检查文件是否存在
    if (new File(findFile(id + ".lua")).exists())
        return id;

    // 4. 通过主题管理器解析
    id = ThemeManager.getKeyboard(id);
    if (mViewCache.containsKey(id))
        return id;
    if (new File(findFile(id + ".lua")).exists())
        return id;

    // 5. 再次回退到当前Rime方案
    id = Rime.getRimeStatus().getSchemaId();
    // ... 更多回退逻辑
}
```

## 第三阶段：键盘视图类型选择

Trime 支持四种键盘布局类型，根据 Lua 配置文件中的关键字段自动选择：

### 3.1 行布局键盘（RowKeyboardView）

**触发条件**：Lua 配置中存在 `rows` 表

**特点**：

- 按键按行组织，每行内的按键水平排列
- 支持百分比宽度和 dp 宽度两种模式
- 适合标准 QWERTY 键盘布局

**Lua 配置示例**：

```lua
-- qwerty.lua
rows = {
    {
        width = 100,  -- 行宽度百分比
        keys = {
            { label = "q", width = 10 },
            { label = "w", width = 10 },
            -- ...
        }
    },
    -- 更多行...
}
```

**Java 实现**：`RowKeyboardView.java` 第 60-68 行

```java
public RowKeyboardView(@NonNull Context context, Globals globals) {
    super(context, globals);
    this.globals = globals;
    String style = globals.get("style").optjstring("keyboard");

    long time = System.currentTimeMillis();
    setBackground(ThemeManager.getStyle().getStyle(style).getBackground(0xffdddddd));
    loadRows();  // 加载行配置
    Log.w("RowKeyboardView", "init time: " + (System.currentTimeMillis() - time));
}
```

### 3.2 绝对定位键盘（AbsKeyboardView）

**触发条件**：Lua 配置中存在 `keys` 表（且没有 `rows` 或 `flex_box`）

**特点**：

- 每个按键可独立指定 x、y 坐标
- 支持精确的像素级定位
- 适合特殊布局需求

**Lua 配置示例**：

```lua
keys = {
    { label = "q", x = 0, y = 0, width = 10, height = 50 },
    { label = "w", x = 10, y = 0, width = 10, height = 50 },
    -- ...
}
```

### 3.3 Flexbox 弹性布局键盘（FlexboxKeyboardView）

**触发条件**：Lua 配置中存在 `flex_box` 表

**特点**：

- 使用 Google FlexboxLayout 实现弹性布局
- 按键自动换行、自适应宽度
- 适合不规则布局

### 3.4 符号键盘（SymbolsKeyboardView）

**触发条件**：Lua 配置中存在 `key_maps` 表

**特点**：

- 显示在自定义视图区域（而非主键盘区）
- 支持分页浏览大量符号
- 通过 `showCustomView()` 切换显示

### 4.2 initView() - 视图结构初始化

**文件**：`KeyView.java` 第 1045-1176 行

```java
private void initView() {
    // 步骤1: 设置基本属性
    setClickable(true);
    setFocusable(true);
    setClipChildren(false);
    setClipToPadding(false);

    // 步骤2: 创建按键根布局容器 keyRoot
    keyRoot = new FrameLayout(getContext());
    keyRoot.setClipChildren(false);
    keyRoot.setClipToPadding(false);

    // 步骤3: 设置阴影颜色（Android P+）
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
        int dShadowColor = mKeyStyle.getShadowColor();
        if (dShadowColor != 0) {
            keyRoot.setOutlineAmbientShadowColor(dShadowColor);
            keyRoot.setOutlineSpotShadowColor(dShadowColor);
        }
    }

    // 步骤4: 构建背景过渡动画（正常状态 → 按下状态）
    Drawable[] layers = new Drawable[2];
    layers[0] = mKeyStyle.getBackground();       // 正常状态背景
    layers[1] = mPressedStyle.getBackground();   // 按下状态背景

    // 特殊处理：Bitmap 背景的颜色滤镜
    if (layers[0] instanceof LuaBitmapDrawable) {
        if (layers[1] instanceof GradientDrawable) {
            PorterDuffColorFilter colorFilter = new PorterDuffColorFilter(
                    mPressedStyle.getBackgroundColor(),
                    PorterDuff.Mode.MULTIPLY
            );
            ((LuaBitmapDrawable) layers[0]).setColorFilter(colorFilter);
            layers[1] = layers[0];
        }
    }

    transition = new TransitionDrawable(layers);
    keyRoot.setBackground(transition);

    // 步骤5: 初始化主文本 TextView (mClick)
    mClick = new TextView(getContext());
    mClick.setIncludeFontPadding(false);  // 移除字体默认内边距
    mClick.setSingleLine(true);           // 单行显示
    mClick.setTextSize(TypedValue.COMPLEX_UNIT_DIP, mKeyStyle.getTextSize());
    mClick.setTextColor(mKeyStyle.getTextColor());
    mClick.setTypeface(mKeyStyle.getFont());

    setVisibility(View.INVISIBLE);  // 初始隐藏，等待内容设置

    // 将 mClick 添加到 keyRoot，居中对齐
    keyRoot.addView(mClick, new FrameLayout.LayoutParams(
            ViewGroup.LayoutParams.WRAP_CONTENT,
            ViewGroup.LayoutParams.WRAP_CONTENT,
            mKeyStyle.getGravity(Gravity.CENTER)
    ));

    // 设置偏移量
    mClick.setTranslationX(mKeyStyle.getSize("offset_x", 0));
    mClick.setTranslationY(mKeyStyle.getSize("offset_y", 0));

    // 步骤6: 设置海拔高度（Elevation）
    int elevation = mKeyStyle.getElevation();
    keyRoot.setElevation(elevation);

    // 步骤7: 计算并设置边距（Margins）
    Style margins = mKeyStyle.getStyle("margins");
    LayoutParams params = new LayoutParams(
            ViewGroup.LayoutParams.MATCH_PARENT,
            ViewGroup.LayoutParams.MATCH_PARENT
    );
    params.setMargins(
            margins.getSize("left", elevation / 3),
            margins.getSize("top", elevation / 3),
            margins.getSize("right", elevation / 3),
            margins.getSize("bottom", elevation / 3)
    );

    // 步骤8: 设置内边距（Padding）
    Style paddings = mKeyStyle.getStyle("paddings");
    mClick.setPadding(
            paddings.getSize("left", 0),
            paddings.getSize("top", 0),
            paddings.getSize("right", 0),
            paddings.getSize("bottom", 0)
    );

    Style padding = mKeyStyle.getStyle("padding");
    keyRoot.setPadding(
            padding.getSize("left", 0),
            padding.getSize("top", 0),
            padding.getSize("right", 0),
            padding.getSize("bottom", 0)
    );

    // 步骤9: 将 keyRoot 添加到 KeyView
    addView(keyRoot, params);

    // 步骤10: 如果配置了预览窗口，则初始化 keyPreview
    if (mKeyStyle.hasKey("preview")) {
        KeyStyle previewStyle = mKeyStyle.getKeyStyle("preview", mKeyStyle);
        keyPreview = new TextView(getContext());
        keyPreview.setIncludeFontPadding(true);
        keyPreview.setOutlineProvider(ViewOutlineProvider.BACKGROUND);
        keyPreview.setClipToOutline(false);
        keyPreview.setBackground(previewStyle.getBackground());
        keyPreview.setVisibility(GONE);  // 初始隐藏
        keyPreview.setGravity(Gravity.CENTER);
        keyPreview.setElevation(previewStyle.getElevation());
        keyPreview.setTextSize(TypedValue.COMPLEX_UNIT_DIP, previewStyle.getTextSize());
        keyPreview.setTextColor(previewStyle.getTextColor());

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
            int dShadowColor = previewStyle.getShadowColor();
            if (dShadowColor != 0) {
                keyPreview.setOutlineAmbientShadowColor(dShadowColor);
                keyPreview.setOutlineSpotShadowColor(dShadowColor);
            }
        }

        addView(keyPreview, new LayoutParams(
                ViewGroup.LayoutParams.MATCH_PARENT,
                ViewGroup.LayoutParams.MATCH_PARENT
        ));
    }

    // 步骤11: 设置轮廓提供者以支持阴影绘制
    keyRoot.setOutlineProvider(ViewOutlineProvider.BACKGROUND);
    keyRoot.setClipToOutline(false);
}
```

### 4.3 initKey() - 按键内容初始化

**文件**：`KeyView.java` 第 1182-1280 行

```java
private void initKey() {
    if (mKey == null) return;

    // 1. 设置主标签文本（Click Label）
    String click = mKey.getLabel();
    if (!TextUtils.isEmpty(click)) {
        setClickText(click);
    }

    // 2. 设置长按标签文本（Long Click Label）
    String longClick = mKey.getLongClickLabel();
    if (!TextUtils.isEmpty(longClick)) {
        setLongClickText(longClick);
    }

    // 3. 设置普通提示文本（Hint）
    String hint = mKey.getHint();
    if (!TextUtils.isEmpty(hint)) {
        setHintText(hint);
    }

    // 4. 设置无障碍描述内容
    setContentDescription(mKey.getDescription());

    // 5. 处理上滑提示（Swipe Up）
    String ev = mKey.getHint(SWIPE_UP);
    if (ev != null) {
        KeyStyle ht;
        LuaValue keyHintUp = mKey.getMk().get("hint_up");
        if (keyHintUp.istable()) {
            // 按键级别配置
            KeyStyle defaultUpStyle = mHintKeyStyle.hasKey("up")
                    ? mHintKeyStyle.getKeyStyle("up", mHintKeyStyle)
                    : mHintKeyStyle;
            ht = new KeyStyle(keyHintUp, defaultUpStyle);
        } else if (mHintKeyStyle.hasKey("up")) {
            // 主题全局配置
            ht = mHintKeyStyle.getKeyStyle("up", mHintKeyStyle);
        } else {
            ht = mHintKeyStyle;
        }
        mHintStyles[SWIPE_UP] = ht;
        if (mHints[SWIPE_UP] != null) {
            mHints[SWIPE_UP].setText(ht.getSpan(ev));
        } else {
            mHints[SWIPE_UP] = addHint(ev, Gravity.TOP, ht);
        }
    }
```

```java
private void loadKey(LuaTable key, double width) {
    // 步骤1: 计算按键宽度
    width = (mWidth * key.get("width").optdouble(width) / 100);

    // 步骤2: 计算按键高度（支持 dp 和百分比两种模式）
    double height;
    double rowHeightPx = mHeight * mRowHeight / 100;
    if (mIsDpMode) {
        double h = key.get("height").optdouble(0);
        height = h > 0 ? ThemeManager.dp2px((float) h) : rowHeightPx;
    } else {
        height = mHeight * key.get("height").optdouble(mRowHeight) / 100;
    }

    // 步骤3: 创建 KeyView 实例
    KeyView keyView = new KeyView(getContext(), new Key(key));

    // 步骤4: 创建布局参数（包含位置和尺寸）
    FrameLayout.LayoutParams layoutParams = new FrameLayout.LayoutParams(
            (int) width,
            (int) height,
            Gravity.TOP | Gravity.LEFT
    );
    layoutParams.leftMargin = (int) mLeft;
    layoutParams.topMargin = (int) mTop;

    // 步骤5: 将按键添加到键盘视图
    addView(keyView, layoutParams);

    // 步骤6: 更新下一个按键的起始位置
    mLeft += width;
}
```

## 第五阶段：键盘切换与动画

### 5.1 setKeyboardView 方法

**文件**：`InputView.java` 第 88-129 行

```java
private void setKeyboardView(KeyboardView keyboardView) {
    // 步骤1: 相同视图无需重复设置
    if (keyboardView.equals(mKeyboardView))
        return;

    // 步骤2: 保存旧视图用于过渡动画
    oldView = mKeyboardView;
    mKeyboardView = keyboardView;

    // 步骤3: 若新视图已有父布局，先移除避免冲突
    ViewParent parent = keyboardView.getParent();
    if (parent != null && parent instanceof ViewGroup) {
        ((ViewGroup) parent).removeView(keyboardView);
    }

    // 步骤4: 同步ASCII模式状态到Rime引擎
    Rime.setRimeOption("ascii_mode", keyboardView.isAsciiMode());

    // 步骤5: 重置Shift状态
    setShifted(false);
    ModifierState.setShifted(false);
    ModifierState.setShiftLock(false);

    // 步骤6: 添加新键盘视图到容器最底层
    addView(keyboardView, 0, new ViewGroup.LayoutParams(
            ViewGroup.LayoutParams.MATCH_PARENT,
            ViewGroup.LayoutParams.MATCH_PARENT
    ));

    // 步骤7: 更新容器高度以匹配键盘高度
    int computedHeight = keyboardView.getComputedKeyboardHeight();
    if (computedHeight > 0) {
        ThemeManager.setComputedKeyboardHeight(computedHeight);
    } else {
        computedHeight = ThemeManager.getKeyboardHeight();
    }
    ViewGroup.LayoutParams lp = getLayoutParams();
    if (lp != null) {
        lp.height = computedHeight;
        setLayoutParams(lp);
    }

    // 步骤8: 旧键盘执行淡出动画
    if (oldView != null) {
        oldView.animate()
                .alpha(0f)                    // 透明度渐变为0
                .setDuration(100)             // 动画时长100ms
                .withLayer()                  // 启用硬件层加速
                .withEndAction(() -> {
                    removeView(oldView);      // 动画结束后移除
                    oldView.setAlpha(1.0f);   // 恢复透明度以备复用
                })
                .start();
    }
}
```

### 5.2 动画效果说明

- **淡入淡出**：新键盘立即显示（alpha=1），旧键盘在 100ms 内渐隐（alpha→0）
- **硬件加速**：`.withLayer()` 启用 GPU 渲染，提升动画流畅度
- **视图复用**：动画结束后恢复旧视图的 alpha 值，便于后续缓存复用

## 性能优化策略

### 7.1 视图缓存机制

**InputView 中的两级缓存**：

```java
// 1. 普通键盘缓存：SchemaId -> KeyboardView
private final Map<String, KeyboardView> mViewCache = new HashMap<>();

// 2. 符号键盘缓存：SchemaId -> SymbolsKeyboardView
private final Map<String, SymbolsKeyboardView> mSymbolsViewCache = new HashMap<>();
```

**优势**：

- 避免重复解析 Lua 脚本
- 避免重复创建 View 对象
- 切换键盘时直接从缓存获取，速度提升显著

### 7.2 懒加载策略

- **InputView 延迟创建**：在 `RootInputView` 构造函数中最后创建，确保 `ThemeManager` 已初始化
- **KeyView 按需创建**：仅在加载键盘时创建需要的按键，不预创建所有可能的按键

### 7.3 硬件加速

- **动画层**：`.withLayer()` 启用 GPU 渲染
- **阴影绘制**：`setOutlineProvider(ViewOutlineProvider.BACKGROUND)` 利用硬件阴影

### 7.4 减少布局嵌套

- **FrameLayout 替代 LinearLayout**：在不需要权重的场景使用更轻量的 FrameLayout
- **扁平化层级**：`KeyView` 内部仅两层（`keyRoot` + `mClick`），避免过深嵌套

### 7.5 背景过渡优化

- **TransitionDrawable**：复用同一背景对象，通过颜色滤镜模拟按下效果，避免创建多个 Drawable

## 总结

Trime 的键盘创建流程可以概括为以下五个阶段：

1. **RootInputView 初始化**：创建根布局容器，搭建整体 UI 框架
2. **InputView 创建**：加载 Lua 脚本，解析键盘配置，选择键盘类型
3. **键盘视图实例化**：根据配置创建 `RowKeyboardView` / `AbsKeyboardView` / `FlexboxKeyboardView`
4. **KeyView 按键生成**：逐个创建按键，设置文本、样式、事件绑定
5. **键盘显示与切换**：添加到视图树，执行淡入淡出动画

整个流程体现了以下设计原则：

- **配置驱动**：通过 Lua 脚本定义键盘布局，灵活可扩展
- **缓存复用**：两级缓存机制避免重复创建
- **样式分离**：`Key` 数据模型与 `KeyStyle` 样式配置解耦
- **性能优先**：硬件加速、懒加载、减少嵌套等多重优化
