## 背景图类型概述

Trime 支持多种类型的背景图片，用于不同的 UI 组件：

| 背景类型 | 用途 | 缓存键名 | 说明 |
|---------|------|---------|------|
| **keyboard** | 键盘面板背景 | `keyboard` | 整个键盘区域的背景图 |
| **key** | 按键背景 | `key` | 单个按键的背景图（可被样式覆盖） |
| **candidate** | 候选词栏背景 | `candidate` | 候选词列表区域的背景 |
| **composition** | 编码区背景 | `composition` | 预编辑文本显示区的背景 |
| **background** | 根布局背景 | `background` | 整个输入法界面的最底层背景 |
| **popup_keyboard** | 弹出键盘背景 | `popup_keyboard` | 长按弹出的浮动键盘背景 |

### 横屏模式支持

所有背景类型都支持横屏专用图片，通过在文件名中添加 `_land` 后缀实现：
- `keyboard_land.png` - 横屏键盘背景
- `key_land.png` - 横屏按键背景
- `candidate_land.png` - 横屏候选词背景
- 等等...

## 存储目录结构

Trime 从 **三个层级** 的目录中加载背景图片，按优先级从高到低排列：

### 📁 完整目录树

```
用户数据目录 (userDataDir)
├── backgrounds/                    ← 第一优先级：全局背景目录
│   ├── keyboard.png               # 竖屏键盘背景
│   ├── keyboard_land.png          # 横屏键盘背景
│   ├── key.jpg                    # 竖屏按键背景
│   ├── key_land.webp              # 横屏按键背景
│   ├── candidate.png
│   ├── composition.png
│   ├── background.png
│   ├── popup_keyboard.png
│   │
│   └── my_theme_package/          ← 第二优先级：主题包目录
│       ├── 1.png                  # 数字索引背景（动态切换用）
│       ├── 2.jpg
│       ├── keyboard.png
│       └── ...
│
└── themes/                         ← 第三优先级：主题目录
    └── default/                   # 当前主题名称（可切换）
        ├── main.lua               # 主题配置文件
        ├── styles/                # 样式子目录
        │   └── green/
        │       └── main.lua
        ├── keyboards/             # 键盘布局
        ├── images/                # 主题内图片目录
        │   └── custom_bg.png      # 可通过样式引用
        ├── keyboard.png           # 主题专属背景
        ├── key.png
        ├── candidate.png
        └── ...
```

### 🔍 目录详解

#### 1. backgrounds/ （全局背景目录）

**路径**：`{userDataDir}/backgrounds/`

**特点**：
- ✅ **最高优先级**，会覆盖主题目录中的同名背景
- ✅ 适用于所有主题的全局背景设置
- ✅ 支持直接放置图片文件
- ✅ 支持子目录作为"主题包"

**典型用途**：
- 用户自定义的统一背景
- 第三方主题包分发
- 动态背景切换（使用数字命名）

#### 2. backgrounds/{package_name}/ （主题包目录）

**路径**：`{userDataDir}/backgrounds/{package_name}/`

**特点**：
- ✅ **第二优先级**
- ✅ 需要在设置中选择"背景包"才会生效
- ✅ 支持数字命名的图片用于动态切换
- ✅ 可以打包分发给其他用户

**配置方法**：
在 Trime 设置中设置 `background_package` 偏好项为包名称（如 `my_theme_package`）

#### 3. themes/{theme_name}/ （主题目录）

**路径**：`{userDataDir}/themes/{theme_name}/`

**特点**：
- ✅ **第三优先级**（最低）
- ✅ 每个主题可以有独立的背景
- ✅ 随主题切换自动更换
- ✅ 可以从 APK assets 中解压默认主题

**典型用途**：
- 主题设计师制作配套背景
- 不同风格的视觉方案
- 主题完整性保证

## 文件命名规范

### 📝 基本命名规则

背景图片的文件名由 **前缀** + **可选后缀** + **扩展名** 组成：

```
<prefix>[_land].<extension>
```

#### 必需部分

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| `prefix` | 背景类型标识符 | `keyboard`, `key`, `candidate` 等 |
| `.extension` | 图片格式 | `.png`, `.jpg`, `.jpeg`, `.webp` |

#### 可选部分

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| `_land` | 横屏专用标识 | `keyboard_land.png` |

### 🎯 标准文件名列表

#### 竖屏背景（Portrait）

```
keyboard.png          # 键盘面板背景
key.png               # 按键背景
candidate.png         # 候选词栏背景
composition.png       # 编码区背景
background.png        # 根布局背景
popup_keyboard.png    # 弹出键盘背景
```

#### 横屏背景（Landscape）

```
keyboard_land.png          # 横屏键盘背景
key_land.png               # 横屏按键背景
candidate_land.png         # 横屏候选词背景
composition_land.png       # 横屏编码区背景
background_land.png        # 横屏根布局背景
popup_keyboard_land.png    # 横屏弹出键盘背景
```

#### 通用命名（任意名称）

```
my_custom_bg.png      # 可通过完整文件名引用
ocean_wave.jpg        # 同样可以通过完整文件名引用
```

### 🔢 数字索引命名（动态切换）

用于通过代码动态切换背景的场景：

```
1.png                 # 索引 1
2.jpg                 # 索引 2
3.webp                # 索引 3
10.png                # 索引 10
```

**注意**：
- 文件名必须是纯数字（不含小数点前的其他字符）
- 扩展名不影响索引值
- 仅对主题包目录有效（`backgrounds/{package}/`）

### 🖼️ 支持的图片格式

| 格式 | 扩展名 | 推荐场景 | 优点 | 缺点 |
|-----|--------|---------|------|------|
| **PNG** | `.png` | 带透明度的背景、按键背景 | 无损压缩、支持 Alpha 通道 | 文件较大 |
| **JPEG** | `.jpg`, `.jpeg` | 照片类背景、渐变背景 | 文件较小 | 不支持透明度、有损压缩 |
| **WebP** | `.webp` | 所有场景（推荐） | 高压缩率、支持透明度 | 旧设备兼容性差 |

**建议**：
- 🎨 需要透明效果 → 使用 PNG 或 WebP
- 📸 照片/渐变背景 → 使用 JPEG 或 WebP
- ⚡ 追求性能 → 使用 WebP（Android 4.0+ 支持）

## 加载优先级机制

### 🔄 三级优先级覆盖

当多个目录中存在同名背景文件时，按以下优先级加载：

```
1️⃣ backgrounds/              （最高优先级）
   ↓ 如果不存在
2️⃣ backgrounds/{package}/   （中等优先级，需启用背景包）
   ↓ 如果不存在
3️⃣ themes/{theme}/          （最低优先级）
```

### 📊 优先级示例

假设用户设置了以下文件：

```
backgrounds/keyboard.png          ← 优先级 1（最终使用这个）
backgrounds/my_pkg/keyboard.png   ← 优先级 2（被覆盖）
themes/default/keyboard.png       ← 优先级 3（被覆盖）
```

**结果**：使用 `backgrounds/keyboard.png`

### 🌅 横屏优先逻辑

在横屏模式下，加载逻辑如下：

```java
// BackUtil.java 第 337-352 行
public static LuaBitmapDrawable get(Context context, String name) {
    name = name.toLowerCase();
    
    // 1. 如果是横屏模式且存在横屏图片，优先使用横屏版
    if (TrimeService.getInstance().isLandscape() 
        && cache_land.containsKey(name)) {
        return new LuaBitmapDrawable(context, cache_land.get(name));
    }
    
    // 2. 否则使用竖屏图片
    if (cache.containsKey(name))
        return new LuaBitmapDrawable(context, cache.get(name));
    
    // 3. 兼容旧版主题（去掉 _color 后缀）
    if (name.endsWith("_color")) {
        name = name.substring(0, name.length() - 6);
        return get(context, name);
    }
    
    return null;
}
```

**示例**：
- 横屏模式下请求 `keyboard` → 返回 `keyboard_land.png`（如果存在）
- 如果 `keyboard_land.png` 不存在 → 降级使用 `keyboard.png`

## 代码实现细节

### 🔧 核心类：BackUtil

**文件位置**：`app/src/main/java/com/osfans/trime/util/BackUtil.java`

#### 数据结构

```java
public class BackUtil {
    // 竖屏背景缓存：键名 -> 文件绝对路径
    private static final HashMap<String, String> cache = new HashMap<>();
    
    // 横屏背景缓存：键名 -> 文件绝对路径
    private static final HashMap<String, String> cache_land = new HashMap<>();
    
    // 数字索引缓存：索引号 -> 文件绝对路径（用于动态切换）
    private static final HashMap<Integer, String> icache = new HashMap<>();
    
    // 颜色值缓存
    private static final HashMap<String, Integer> colors = new HashMap<>();
    
    // 像素值缓存（尺寸、间距、圆角等）
    private static final HashMap<String, Float> pixels = new HashMap<>();
}
```

#### 初始化流程：reset() 方法

**调用时机**：
- 应用启动时
- 切换主题时
- 用户手动刷新背景时

**执行步骤**：

```java
public static void reset(Context context) {
    // 步骤1: 清空所有缓存
    cache.clear();
    cache_land.clear();
    icache.clear();
    icache2.clear();
    colors.clear();
    pixels.clear();
    
    String userDataDir = DataManager.getUserDataDir().getAbsolutePath();
    
    // 步骤2: 扫描 backgrounds/ 目录（优先级1）
    File dir = new File(userDataDir, "backgrounds");
    if (dir.exists()) {
        scanDirectory(dir, cache, cache_land, false);
    }
    
    // 步骤3: 扫描 backgrounds/{package}/ 目录（优先级2）
    String pkg = Function.getPref(context).getString("background_package", "none");
    if (!pkg.equals("none")) {
        dir = new File(new File(userDataDir, "backgrounds"), pkg);
        if (dir.exists()) {
            scanDirectory(dir, cache, cache_land, true); // 启用数字索引
        }
    }
    
    // 步骤4: 扫描 themes/{theme}/ 目录（优先级3）
    dir = new File(userDataDir, Config.getTheme());
    if (dir.exists()) {
        scanDirectory(dir, cache, cache_land, false);
    }
    
    // 步骤5: 加载用户自定义颜色和尺寸配置
    loadCustomColorsAndSizes(context);
}
```

#### 文件扫描逻辑

```java
private static void scanDirectory(File dir, 
                                   HashMap<String, String> cache,
                                   HashMap<String, String> cache_land,
                                   boolean enableIndexCache) {
    File[] files = dir.listFiles(pathname -> pathname.isFile());
    
    if (files == null) return;
    
    for (File file : files) {
        String fileName = file.getName().toLowerCase();
        String absolutePath = file.getAbsolutePath();
        
        // === 识别背景类型并分类缓存 ===
        
        // 1. 键盘背景
        if (fileName.startsWith("keyboard.")) {
            cache.put("keyboard", absolutePath);
        }
        // 2. 弹出键盘背景
        else if (fileName.startsWith("popup_keyboard.")) {
            cache.put("popup_keyboard", absolutePath);
        }
        // 3. 按键背景
        else if (fileName.startsWith("key.")) {
            cache.put("key", absolutePath);
        }
        // 4. 根布局背景
        else if (fileName.startsWith("background.")) {
            cache.put("background", absolutePath);
        }
        // 5. 候选词背景
        else if (fileName.startsWith("candidate.")) {
            cache.put("candidate", absolutePath);
        }
        // 6. 编码区背景
        else if (fileName.startsWith("composition.")) {
            cache.put("composition", absolutePath);
        }
        
        // 同时以完整文件名作为键存储（支持自定义名称）
        cache.put(fileName, absolutePath);
        
        // === 识别横屏图片 ===
        if (fileName.startsWith("keyboard_land.")) {
            cache_land.put("keyboard", absolutePath);
        } else if (fileName.startsWith("popup_keyboard_land.")) {
            cache_land.put("popup_keyboard", absolutePath);
        } else if (fileName.startsWith("key_land.")) {
            cache_land.put("key", absolutePath);
        } else if (fileName.startsWith("background_land.")) {
            cache_land.put("background", absolutePath);
        } else if (fileName.startsWith("candidate_land.")) {
            cache_land.put("candidate", absolutePath);
        } else if (fileName.startsWith("composition_land.")) {
            cache_land.put("composition", absolutePath);
        } else if (fileName.contains("_land.")) {
            // 通用横屏图片：将 _land. 替换为 . 后存入横屏缓存
            String landKey = fileName.replace("_land.", ".");
            cache_land.put(landKey, absolutePath);
        }
        
        // === 数字索引缓存（仅主题包目录） ===
        if (enableIndexCache) {
            try {
                String nameWithoutExt = fileName.substring(0, fileName.indexOf("."));
                int index = Integer.parseInt(nameWithoutExt);
                icache.put(index, absolutePath);
            } catch (Exception e) {
                // 解析失败则忽略（非数字文件名）
            }
        }
    }
}
```

### 🎨 Style.getDrawable() 方法

**文件位置**：`app/src/main/java/com/osfans/trime/theme/Style.java`

除了 `BackUtil` 管理的背景外，样式配置中也可以直接指定背景图片：

```java
public Drawable getDrawable(String key) {
    LuaValue v = mTable.get(key);
    
    // 预先计算圆角半径
    float radiusPx = dp2px((float) mTable.get("corner_radius").optdouble(0f));
    
    if (v.isint()) {
        // 情况1: 配置的是颜色值（整数）
        // 创建 GradientDrawable（纯色背景）
        return createGradientDrawable(
            v.toint(), 
            radiusPx,
            dp2px((float) mTable.get("stroke_width").optdouble(0)), 
            mTable.get("stroke_color").optint(0)
        );
        
    } else if (v.isstring()) {
        // 情况2: 配置的是图片路径（字符串）
        
        // 先尝试从样式目录加载
        File f = new File(Config.getStylePath(v.tojstring()));
        if (f.exists())
            return new LuaBitmapDrawable(f.getAbsolutePath());
        
        // 再尝试从主题 images 目录加载
        f = new File(Config.getImagePath(v.tojstring()));
        if (f.exists())
            return new LuaBitmapDrawable(f.getAbsolutePath());
    }
    
    return null;
}
```

**Lua 配置示例**：

```lua
-- 方式1: 使用颜色值
key = {
    background = 0xFFFFFFFF  -- 白色背景
}

-- 方式2: 使用图片路径（相对于主题目录）
key = {
    background = "key_bg.png"  -- 从 themes/{theme}/images/ 加载
}

-- 方式3: 使用样式目录的图片
key = {
    background = "styles/green/key.png"  -- 从 themes/{theme}/styles/green/ 加载
}
```

### 🖼️ LuaBitmapDrawable 类

**作用**：封装 Android Bitmap 为 Drawable，支持从文件路径加载

**关键特性**：
- 支持 PNG、JPEG、WebP 格式
- 自动处理图片缩放
- 支持透明度
- 可与 ColorFilter 结合实现按下效果

**使用示例**：

```java
// 从文件路径创建
LuaBitmapDrawable drawable = new LuaBitmapDrawable(context, "/path/to/image.png");

// 设置为 View 背景
view.setBackground(drawable);

// 应用颜色滤镜（模拟按下效果）
PorterDuffColorFilter filter = new PorterDuffColorFilter(
    0x80000000,  // 半透明黑色
    PorterDuff.Mode.MULTIPLY
);
drawable.setColorFilter(filter);
```

space.text_size = 18

enter = table.clone(key)
enter.text_size = 18
enter.background = 0xFF4CAF50  -- 绿色回车键
enter.text_color = 0xFFFFFFFF
enter.pressed.background = 0xFF388E3C

## 常见问题与最佳实践

### ❓ 常见问题

#### Q1: 为什么我放置的背景图片没有生效？

**检查清单**：
1. ✅ 文件名是否正确（区分大小写）
2. ✅ 图片格式是否支持（PNG/JPEG/WebP）
3. ✅ 文件是否放在正确的目录
4. ✅ 是否重启了输入法或切换了主题
5. ✅ 是否有更高优先级的同名文件覆盖

**解决方法**：
```bash
# 1. 确认文件位置
ls -la /sdcard/Documents/Rime/backgrounds/

# 2. 检查文件名
# 应该是 keyboard.png 而不是 Keyboard.PNG

# 3. 强制刷新背景
# 在 Trime 设置中切换一次主题，或重启输入法服务
```

#### Q2: 如何为横屏和竖屏使用不同的背景？

**方法**：同时提供竖屏和横屏两个版本

```
backgrounds/
├── keyboard.png          # 竖屏使用（例如 1080x1920）
└── keyboard_land.png     # 横屏使用（例如 1920x1080）
```

**注意**：
- 横屏图片文件名必须包含 `_land` 后缀
- 系统会自动检测屏幕方向并选择合适的图片
- 如果横屏图片不存在，会降级使用竖屏图片（可能拉伸变形）

#### Q3: 如何实现动态切换背景？

**步骤**：

1. **准备数字命名的图片**：
```
backgrounds/my_package/
├── 1.png
├── 2.jpg
├── 3.webp
└── 4.png
```

2. **在 Lua 脚本中切换**：
```lua
-- 切换到索引为 2 的背景
local drawable = BackUtil.get(luaContext, 2)
if drawable then
    keyboardView.setBackground(drawable)
end
```

3. **或通过事件触发**：
```lua
-- 绑定到某个按键
{
    label = "换背景",
    click = "BackUtil.switch_background()"
}
```

#### Q4: 背景图片太大导致内存溢出怎么办？

**优化建议**：

1. **压缩图片**：
   - 使用 TinyPNG、ImageOptim 等工具压缩
   - 推荐分辨率：不超过屏幕分辨率的 1.5 倍
   - 推荐文件大小：< 500KB

2. **使用 WebP 格式**：
   ```bash
   # 转换 PNG 为 WebP
   cwebp input.png -o output.webp -q 80
   ```

3. **降低色彩深度**：
   - 纯色背景 → 使用 1x1 像素平铺
   - 渐变背景 → 使用窄条图片（如 1x100 像素）

4. **使用颜色值代替图片**：
   ```lua
   -- 推荐：使用颜色值（零内存开销）
   background = 0xFFE8F5E9
   
   -- 不推荐：使用大图
   background = "huge_background.png"
   ```

#### Q5: 如何让背景支持透明度？

**方法**：使用 PNG 或 WebP 格式，并确保图片包含 Alpha 通道

**示例**：
```lua
-- 半透明按键背景
key = {
    background = "semi_transparent_key.png",  -- PNG with alpha
    -- 或使用 ARGB 颜色值
    -- background = 0x80FFFFFF  -- 50% 透明白色
}
```

**注意**：
- JPEG 不支持透明度
- 透明度会影响性能（需要混合渲染）
- 建议在按键上使用轻微透明度（20%-50%），避免完全透明

#### 2. 图片尺寸建议

| 背景类型 | 推荐尺寸（竖屏） | 推荐尺寸（横屏） | 最大文件大小 |
|---------|----------------|----------------|------------|
| background | 1080x2400 | 2400x1080 | 500KB |
| keyboard | 1080x600 | 2400x400 | 300KB |
| key | 200x150 | 200x150 | 50KB |
| candidate | 1080x150 | 2400x120 | 200KB |
| composition | 1080x100 | 2400x80 | 150KB |

**提示**：
- 按键背景可以使用小尺寸图片平铺
- 渐变背景可以使用 1xN 像素的窄条图片
- 纯色背景建议使用颜色值而非图片

#### 3. 性能优化技巧

```lua
-- ✅ 好：使用颜色值（最快）
key = {
    background = 0xFFFFFFFF
}

-- ✅ 好：使用小尺寸 WebP
key = {
    background = "key_bg.webp"  -- 200x150, 10KB
}

-- ⚠️ 一般：使用 PNG（支持透明度）
key = {
    background = "key_bg.png"  -- 200x150, 30KB
}

-- ❌ 差：使用大图（慢且耗内存）
key = {
    background = "huge_photo.jpg"  -- 1920x1080, 2MB

```

#### 4. 兼容性考虑

**Android 版本兼容性**：

| 特性 | 最低 Android 版本 | 说明 |

**建议**：
- 如果目标用户包含旧设备，提供 PNG 备选
- 使用 `Build.VERSION.SDK_INT` 检测版本

## 总结

### 📌 核心要点

1. **三级优先级**：`backgrounds/` > `backgrounds/{package}/` > `themes/{theme}/`
2. **横屏支持**：添加 `_land` 后缀实现横屏专用背景
3. **文件命名**：`<type>[_land].<ext>` 格式
4. **加载机制**：启动时扫描目录，缓存文件路径，按需创建 Drawable
5. **配置灵活**：支持颜色值、图片路径两种方式
6. **动态切换**：使用数字索引实现运行时背景切换

### 🚀 快速上手

**最简单的背景配置**：

```lua
-- themes/my_theme/main.lua
background = 0xFFE8F5E9  -- 纯色背景（推荐）

keyboard = {
    background = 0xFFFFFFFF
}

key = {
    background = 0xFFFFFFFF,
    corner_radius = 10
}
```

**使用图片背景**：

```lua
-- 1. 放置图片到 themes/my_theme/
-- keyboard.png, key.png, etc.

-- 2. 在配置中引用
keyboard = {
    background = "keyboard.png"
}

key = {
    background = "key.png"
}
```

**横屏适配**：

```
themes/my_theme/
├── keyboard.png          # 竖屏
├── keyboard_land.png     # 横屏
├── key.png

```
